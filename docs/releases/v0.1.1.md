# Warden v0.1.1

Warden v0.1.1 is a stable public-preview release.

- Moves account behavior onto the canonical Gantry Core multi-account model
  without retaining the legacy password-hash migration path.
- Adds capability-scoped management and launcher administration.
- Corrects the `/manage/` layout and aligns launcher/login presentation.
- Adds headless setup, confirmation-protected reset commands and consistent
  service lifecycle output.
- Pins Gantry Core v0.1.0 for reproducible standalone builds.
